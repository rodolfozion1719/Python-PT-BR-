# 🐍 Trilha de Aprendizado: Python para IA

Repositório dedicado ao armazenamento dos meus cadernos de estudo (Jupyter Notebooks sobre Python) desenvolvidos durante o Bacharelado em Inteligência Artificial na Universidade Federal de Jataí (UFJ).

## 📚 Conteúdo Abordado
Este repositório documenta minha evolução prática na programação, contendo exercícios e implementações de:
- **Fundamentos:** Estruturas de controle, laços de repetição, listas, matrizes e manipulação de arquivos.
- **Engenharia de Software:** Funções, modularização e Programação Orientada a Objetos (POO).
- **Ciência de Dados & Machine Learning:** Utilização prática de bibliotecas essenciais como `NumPy`, `Pandas`, `Matplotlib` e introdução a classificadores com `Scikit-Learn` (KNN).
- **Lógica de Programação:** Resolução de problemas focados em maratonas de programação (Beecrowd).
